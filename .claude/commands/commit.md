# /commit

Propose a Conventional Commit message based on current changes.

Required:
- Type from: feat, fix, docs, test, refactor, chore
- Short subject in imperative style
- Body explaining why
- Optional AI disclosure footer if AI-assisted:
  - `Co-Authored-By: Claude <noreply@anthropic.com>`

Output:
- One primary commit message
- One alternative message
